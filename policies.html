특약 분석 7단계 체크리스트

보험금 지급 여부를 검토할 때 다음 순서를 지킵니다.

  1. 정확한 상품명과 약관 버전 확인
  2. 특별약관의 정확한 명칭 확인
  3. 보험금 지급사유와 지급 단위 구분
  4. 최초 1회·연간 1회 등 지급 제한 확인
  5. 면책사항과 보장개시일 확인
  6. 해당 약관 조항과 PDF 페이지 표시
  7. 확인되지 않은 사항은 ‘검증 불가’로 표시
약관 확인 원칙

같은 상품이라도 판매 시기와 특약 명칭에 따라 보장 기준이 다를 수 있습니다. 서로 다른 특약의 지급 횟수나 보장개시일을 혼용하지 않습니다. 보험금 지급 여부는 해당 계약의 약관, 가입 내용 및 실제 사고·치료 사실관계에 따라 판단됩니다.

현재 페이지는 자료실의 기본 구조이며 실제 PDF 원문 및 조항별 분석자료는 아직 연결되지 않았습니다. 고객 개인정보나 비공개 내부 자료는 공개 GitHub Pages에 업로드하지 마세요.
